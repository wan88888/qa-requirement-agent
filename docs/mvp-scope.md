## 手动体验路径

1. 工作台选择“体验示例”，点击“开始评审”。
2. 确认演示标识清晰可见，报告有 8 条意见及 8 条可核验引用。
3. 点击 P1 应筛选出 3 条；点击引用应高亮原文。
4. 将一条意见改为“已采纳”，刷新页面或重新进入，状态仍保留。
5. 导出 Markdown/JSON，核实八章节、指纹、问题与人工确认状态。
6. 粘贴另一份需求：结果应来自该文本，不能套用退款样例问题。
7. 未配置时选择真实评审，获得明确配置错误，不生成伪造报告。
8. 连接设置、评审标准、历史搜索和窄屏导航可使用。

## 真实试运行待办

配置实际模型与飞书身份后，使用一份获授权的测试 PRD，核实 wiki 解析、正文完整性、权限失败、结构化输出和报告回读。检查新报告真实可见范围。若 MCP schema 与当前适配字段不同，按实际 schema 调整适配器并补充回归用例。

调研中的成功率、有效问题占比和关键问题召回率是试运行目标，不是本次实测结果。后续需要人工标注样本才能评估这些质量指标。

图文评审补充：支持飞书图片预览、画板截图与节点读取、长图分片、视觉证据定位和部分失败记录；不保证 OCR/流程识别无误，全部视觉证据需人工复核。
